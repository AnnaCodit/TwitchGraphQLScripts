# TwitchGraphQLScripts

Useful scripts to use graphql

[Русская документация](./RU_README.md)

## Followers loader

Loads all user followers, command:

```bash
python3 followers.py <streamer>
```

## Following loader

Loads all streamers that user follows, command:

```bash
python3 following.py <user>
```

## Followers analytics

[followers_analytics.ipynb](./followers_analytics.ipynb) provides an example, how to draw streamer followers histogram.
