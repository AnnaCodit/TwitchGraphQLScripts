# TwitchGraphQLScripts

Полезные скрипты, использующие Twitch graphql

## Загрузка фолловеров

Загружает всех фолловеров некоторого стримера, команда для вызова:

```bash
python3 followers.py <streamer>
```

## Загрузка всех, на кого подписан

Загрузка всех, на кого подписан какой-нибудь пользователь, команда для вызова:

```bash
python3 following.py <челикс>
```

## Followers analytics

[followers_analytics.ipynb](./followers_analytics.ipynb) пример, как нарисовать гистограму подписок на какого-нибудь стримера.
